# SvelteJS Stimulated Task: Focus Flow Planner

An interactive daily focus planner built with Svelte 5 and SvelteKit.

## Features

- Reactive task, completion, focus-time, and progress metrics
- Add new tasks with category and time estimates
- Mark tasks as complete
- Filter all, open, or completed tasks
- Responsive desktop and mobile design

## Run

```bash
source /root/.nvm/nvm.sh
nvm use 20.19.5
npm install
npm run dev
```

Open http://localhost:5173 in a browser. If that port is busy, use the URL printed in the terminal.

## Verify

```bash
npm run check
npm run lint
npm test
npm run build
```
